본 화면은 IBM watsonx Orchestrate 데모를 위한 목업(시안)이며 실제 교보증권의 서비스, 시세, 공지가 아닙니다.

화면의 수치와 공지는 예시이고, 챗 응답은 합성 데이터(FIN_DEMO)를 조회한 결과입니다. 고객 정보는 모두 가상입니다.

한국어 질문을 SQL로 바꿔 조회하고, 용어집과 메타데이터로 의미를 확인하며, 차트와 근거까지 보여주는 Text-to-SQL 데모입니다.

용어·메타데이터 검색 에이전트는 용어와 구조를 직접 묻는 질문에만 쓰이고 값 조회 흐름에는 끼지 않습니다. SQL 에이전트와 Insight 에이전트는 같은 map_terms 툴로 wxdi 용어집을 읽어 동의어를 표준 용어로 바꾼 뒤 SQL을 만들기 때문에, 결과가 용어집에 따라 달라집니다. 차트와 원인 질문은 SQL 에이전트를 건너뛰고 Insight가 처리합니다. 하위 에이전트의 모델은 gpt-oss-120b입니다.

어떻게 동작하나

  • watsonx Orchestrate(wxO)는 에이전트가 툴을 부르는 곳입니다. LLM은 호출 순서, 재시도, 답변 정리만 맡습니다.
  • watsonx.data intelligence(wxdi)는 데이터 설명서(카탈로그, 용어집)와 Text-to-SQL REST를 제공합니다. SQL을 만들기만 하고 실행하지는 않습니다.
  • Db2는 데이터가 있는 곳입니다. 만들어진 SQL은 Db2로 직접 실행하며, 조회(SELECT)만 허용합니다.

툴하는 일연결 대상주요 출력
generate_sql한국어 질문을 Db2 SQL로 바꿉니다. 도메인 규칙 10개를 instructions로 넘기고, 알려진 오류(오조인, 최신일 필터 누락, 연도 없는 월별 묶기 등)는 걸러 최대 3번 재생성합니다. 실행하지는 않습니다.wxdi Text-to-SQL RESTok, sql, score, error

SQL 품질을 지키는 장치

  • instructions 10개: 스키마 인용 규칙, 조인 경로, 종목명과 지점명 처리, 거래대금 동의어, 업종, 한도 소진율, 날짜, 숫자 단위(1억 = 100000000) 등
  • check_sql: EXEC_ID와 ORDER_ID를 잇는 오조인, ACCOUNT_ID와 CUSTOMER_ID 오조인, 최신일 필터 없는 포지션 조회, 거래대금에 불필요한 테이블 조인, 연도 없는 월별 묶기를 감지하면 오류 설명을 붙여 다시 생성
  • fix_qualifiers: Db2가 거부하는 컬럼 한정 방식을 "FIN_DEMO"."T"."C" 형태로 자동 교정

  • 생성기의 비결정성: 같은 질문도 요청마다 SQL이 달라질 수 있습니다. 30분 넘게 미체결인 주문, 잔고 1억 이상 고객 질문이 특히 약합니다.
