OPTION A

SQL을 wxO 에이전트가 직접 씁니다

B안과 같은 구성에서 한 가지만 바꿨습니다. B안은 generate_sql에서 watsonx.data intelligence(wxdi) Text-to-SQL을 호출합니다. A안은 watsonx Orchestrate(wxO)의 gpt-oss-120b 에이전트가 wxdi 용어집과 카탈로그를 읽고 Db2 SQL을 작성합니다. 용어집, 카탈로그, Db2 실행은 그대로입니다.

       SUM(E.EXEC_AMOUNT) AS TOTAL_AMOUNT
FROM FIN_DEMO.EXECUTIONS E
JOIN FIN_DEMO.ORDERS O ON E.ORDER_ID = O.ORDER_ID
JOIN FIN_DEMO.ACCOUNT A ON O.ACCOUNT_ID = A.ACCOUNT_ID

S2-01VIP 고객 중 예수금 많은 순으로 10명

wxO 에이전트(gpt-oss-120b)가 쓴 SQL

SELECT C.CUSTOMER_ID,
       C.CUSTOMER_NAME,
       SUM(B.CASH_BALANCE) AS TOTAL_CASH
FROM FIN_DEMO.CUSTOMER C
JOIN FIN_DEMO.ACCOUNT A ON C.CUSTOMER_ID = A.CUSTOMER_ID
JOIN FIN_DEMO.BALANCE_DAILY B ON A.ACCOUNT_ID = B.ACCOUNT_ID
WHERE C.GRADE = 'VIP'
  AND B.BASE_DATE = (SELECT MAX(BASE_DATE) FROM FIN_DEMO.BALANCE_DAILY)
GROUP BY C.CUSTOMER_ID, C.CUSTOMER_NAME
ORDER BY TOTAL_CASH DESC
FETCH FIRST 10 ROWS ONLY

골든 SQL

SELECT c.CUSTOMER_NAME, SUM(b.CASH_BALANCE) AS CASH FROM FIN_DEMO.CUSTOMER c JOIN FIN_DEMO.ACCOUNT a ON a.CUSTOMER_ID = c.CUSTOMER_ID JOIN FIN_DEMO.BALANCE_DAILY b ON b.ACCOUNT_ID = a.ACCOUNT_ID WHERE c.GRADE = 'VIP' AND b.BASE_DATE = (SELECT MAX(BASE_DATE) FROM FIN_DEMO.BALANCE_DAILY) GROUP BY c.CUSTOMER_ID, c.CUSTOMER_NAME ORDER BY CASH DESC FETCH FIRST 10 ROWS ONLY
S2-02이번 달 약정 상위 고객 5명

wxO 에이전트(gpt-oss-120b)가 쓴 SQL

SELECT
    C.CUSTOMER_NAME AS 고객명,
    C.CUSTOMER_ID AS 고객ID,
    SUM(E.EXEC_AMOUNT) AS 총약정금액
FROM FIN_DEMO.EXECUTIONS E
JOIN FIN_DEMO.ORDERS O

JOIN FIN_DEMO.CUSTOMER C
  ON A.CUSTOMER_ID = C.CUSTOMER_ID
WHERE YEAR(DATE(E.EXEC_TS)) = YEAR(CURRENT DATE)
  AND MONTH(DATE(E.EXEC_TS)) = MONTH(CURRENT DATE)
GROUP BY C.CUSTOMER_NAME, C.CUSTOMER_ID
ORDER BY 총약정금액 DESC
FETCH FIRST 5 ROWS ONLY

S5-02한도 대비 노출금액 비율이 80%를 넘는 데스크가 있어?

wxO 에이전트(gpt-oss-120b)가 쓴 SQL

SELECT D.DESK_NAME,
       D.LIMIT_AMOUNT,
       SUM(P.EXPOSURE_AMOUNT) AS TOTAL_EXPOSURE,
       (SUM(P.EXPOSURE_AMOUNT) / D.LIMIT_AMOUNT) AS RATIO
FROM FIN_DEMO.DESK D
JOIN FIN_DEMO.ST_POSITIONS P ON D.DESK_ID = P.DESK_ID
WHERE P.BASE_DATE = (SELECT MAX(BASE_DATE) FROM FIN_DEMO.ST_POSITIONS)
GROUP BY D.DESK_ID, D.DESK_NAME, D.LIMIT_AMOUNT
HAVING (SUM(P.EXPOSURE_AMOUNT) / D.LIMIT_AMOUNT) > 0.8

골든 SQL

SELECT d.DESK_NAME FROM FIN_DEMO.ST_POSITIONS s JOIN FIN_DEMO.DESK d ON s.DESK_ID = d.DESK_ID WHERE s.BASE_DATE = (SELECT MAX(BASE_DATE) FROM FIN_DEMO.ST_POSITIONS) GROUP BY d.DESK_NAME, d.LIMIT_AMOUNT HAVING SUM(s.EXPOSURE_AMOUNT) / d.LIMIT_AMOUNT > 0.8
용어집 정의는 B안과 같은 wxdi 용어집을 씁니다. 그래서 이 수치는 "wxdi 용어집과 카탈로그를 제공받은 gpt-oss-120b"의 결과이며, 메타데이터 없이 모델만 쓴 결과가 아닙니다. 감독 에이전트를 거친 전체 경로는 이 평가에 포함하지 않았습니다.

평가로 찾은 문제

보정 전 평가에서는 S3-03(업종 내 순위) 한 문항이 불일치여서 10문항 중 9개만 통과하는 실행이 있었습니다. 에이전트가 질문에 없던 FETCH FIRST 20 ROWS ONLY를 SQL에 붙여 32행 중 20행만 가져온 것이 원인이었습니다. 지시문의 "표는 20행까지 보여준다"는 답변 규칙을 SQL 제한으로 잘못 옮긴 것입니다.

"개수를 정하지 않은 질문에는 FETCH FIRST를 붙이지 않고, 20행 제한은 답변에서만 적용한다"는 규칙을 option_a_sql_agent와 option_a_insight_agent 지시문에 추가한 뒤 3회 모두 10/10이었습니다.
