# 시나리오 질문 목록 (1막~6막, 8막 일부)

이 목록은 에이전트 시연과 평가용이다. 막마다 보여 주려는 능력이 분명한 질문만 골랐고, 어렵지 않게 썼다.

- **골든** 표시가 있는 10문항(S1-01, S1-02, S1-03, S2-01, S2-02, S2-04, S2-05, S3-03, S3-04, S5-02)은 SQL 정답이 있다. `shared/spec/golden/golden.json`에 같은 ID와 같은 문구로 들어 있고, 골든 평가(`option_b_watsonxdata/tests/eval_golden.py`)가 SQL 실행 결과로 채점한다. 문구를 바꾸지 않는다.
- 골든이 아닌 질문은 Supervisor 에이전트에 직접 물어 시험한다(2026-11-21). 결과는 HTML "질문별 검증 현황" 탭에 있다.
- 2단계 항목(7막, 8막의 감사 로그와 동시 사용)은 맨 아래에 따로 둔다.
