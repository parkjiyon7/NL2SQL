# 시나리오 질문 목록 (1막~6막, 8막 일부)

이 목록은 에이전트 시연과 평가용이다. SQL 정답이 있는 질문은 `shared/spec/golden/golden.json`에 같은 ID로 들어 있고, 골든 평가(`option_b_watsonxdata/tests/eval_golden.py`)가 SQL 실행 결과로 채점한다.
골든에 없는 질문(S2-03, S3-01, S3-02, S3-05, 4막 대화, S5-01, S5-03, 6막 차트)은 에이전트로 직접 시험한다. 골든 질문은 채점이 가능하도록 문구를 구체화한 것이 있다(예: "우리 지점"을 강남지점으로, "상위 고객"을 상위 5명으로).
2단계 항목(7막, 8막의 감사 로그와 동시 사용)은 맨 아래에 따로 둔다.

## 1막. 단순 조회, 집계, 조건 검색 (김지점)

| ID | 질문 | 요소 |
|---|---|---|
| S1-01 | 오늘 우리 지점 체결 건수와 거래대금 알려줘 | COUNT, SUM, 날짜, 지점 |
| S1-02 | 잔고가 1억 이상인 고객 보여줘 | WHERE, ORDER BY, PII 컬럼 |
| S1-03 | 삼성전자 어제 체결 중 매수만 보여줘 | 종목명을 코드로, 조건 검색 |

## 2막. 업무용어, 동의어 매핑 (김지점)

| ID | 질문 | 매핑 |
|---|---|---|
| S2-01 | VIP 고객 중 예수금 많은 순으로 10명 | VIP 등급 정의, 예수금은 `cash_balance`(스냅샷 테이블이라 최근 기준일 값만) |
| S2-02 | 이번 달 약정 상위 고객 | 약정은 거래대금 동의어 |
| S2-03 | 미수 있는 계좌 보여줘 | 미수는 `receivable` |
| S2-04 | 신용융자 계좌 보여줘 | 신용융자 여부 컬럼 |
| S2-05 | 이번 달 체결대금 상위 고객 | 같은 용어의 다른 동의어 (S2-02와 결과 동일) |

## 3막. 다중 JOIN, Window, 복합 조건 (김지점, 박트레이더)

| ID | 질문 | 요소 |
|---|---|---|
| S3-01 | 이번 달 약정 상위 10 고객과 이들의 주력 종목 | 5-way JOIN, 서브쿼리 |
| S3-02 | 고객별 월 거래대금과 전월 대비 증감률 | LAG, PARTITION BY |
| S3-03 | 종목별 거래대금 순위를 섹터 내에서 매겨줘 (골든 문구: "종목별 거래대금을 업종 내에서 순위 매겨줘") | RANK OVER PARTITION BY |
| S3-04 | 주문 후 30분 넘게 미체결인 지정가 주문 | LEFT JOIN, anti-join, 시간 계산 |
| S3-05 | 계좌 잔고의 7일 이동평균 | ROWS BETWEEN 6 PRECEDING |

## 4막. 모호 질의 재질문, 대화형 (김지점)

| ID | 발화 | 기대 동작 |
|---|---|---|
| S4-01 | 수익 좋은 고객 보여줘 | 수익 기준(실현손익, 평가손익, 수익률), 기간, 인원을 되묻는다 |
| S4-02 | 이번 분기 실현손익 기준 상위 10명 | S4-01의 응답. 질의 실행 |
| S4-03 | 그 중에 코스닥 종목 위주로 거래한 고객만 | 직전 결과 맥락 유지 |
| S4-04 | 작년 같은 기간이랑 비교해줘 | 맥락 유지, 기간 계산 |

S4-01~S4-04는 한 대화 흐름으로 평가한다.
